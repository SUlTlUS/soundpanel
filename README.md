# 音量面板

一个面向 ColorOS 17 的 LSPosed 音量面板增强模块。在尽量保留系统原生音量逻辑、材质与交互的基础上，对收起/展开布局和快捷操作进行调整。

采用 [JingMatrix/libxposed-api](https://github.com/JingMatrix/libxposed-api) 说明中的 API 102：`compileOnly("io.github.libxposed:api:102.0.0")`，作用域服务为 `service:102.0.0`，模块最低和目标 API 均为 102。发布版使用推荐的入口保留及资源名称适配规则；API 类由 LSPosed 提供，不打包到模块 APK。

## 1. 主要功能

- 所有框架玻璃模态面板使用本地框架 2026-10-17 的共用圆角绘制修复：高光保留真实圆角类型，四份高光/折射着色器按居中坐标选择四角半径。四个颜色入口和玻璃日志检查面板共用该修复，保留原有圆角、材质、阴影及交互参数；纯色外观和 ColorOS 原组件沿用各自的绘制实现。接入与验证见 [模态面板修复记录](docs/modal-framework-corners.md)。

- 模态面板后方不再叠加暗色遮罩：颜色面板、玻璃日志面板使用透明外部关闭层，原生日志弹窗关闭窗口 dim；点击外部仍会关闭面板。

- “面板 → 显示 → 关闭游戏时的自动多应用音量条”默认关闭。现场确认截图中的游戏、视频独立滑条来自游戏助手 `com.oplus.games` 的 `MultiVolumeManager` 独立窗口；开启开关后拦截其按键自动显示协程首次执行。首次使用需通过下方“授权游戏助手作用域”入口授权，并重启游戏助手加载 Hook。保留 SystemUI 主媒体滑条、手动应用音量调节和音频数据，关闭模块或开关后下一次按键恢复原生行为。之前无效的 SystemUI repository View 隐藏试探已撤除；SystemUI 原侧边行策略仍保留。[实际宿主与接口证据](evidence/multi-app-volume-toggle/games-20261017/README.md)。

- 颜色网格在原有 296dp 模式区域内按 12 列、10 行等比缩放，色块和选择框均保持正方形，兼容关闭液态玻璃后的系统密度。

- 应用诊断会同步保留最后一次 Java 未捕获异常，附加到“设置 → 日志 → 导出日志”。记录后仍交由系统处理异常，不吞掉崩溃；颜色面板已恢复框架实现，原生方案历史记录见 [颜色面板承载说明](docs/native-color-picker-sheet.md)。

- 面板页“音量图标颜色”为媒体、铃声、通知、闹钟分别选色，按框架 [Inline 与 Popup 接入方法](../liquidglass_sketch/docs/glass-backdrop-integration.md) 移植原版 `Ios27ColorPickerDialog` 及其依赖。保留 599dp 面板、原稿工具栏图标、完整预设色区域、加号按钮、圆角和材质；标题、网格/光谱/滑块、RGB 通道、不透明度与十六进制颜色说明适配中文，工具栏补充中文无障碍标签。预设色列按左侧 105dp 留白后的剩余宽度测量，在框架 402dp 参考宽度下仍为 249dp；关闭液态玻璃、使用系统密度时也保持右侧色点及加号位于内容内。打开时上滑淡入，关闭时下滑淡出并在动画完成后移除；原版关闭图标、返回键或点击外部关闭时保存，应用设置分组另设“还原系统颜色”。颜色同步至 LSPosed、Provider 和持久缓存，下次显示时应用于原生动态图标绘制，保留图标的静音/蓝牙状态及动画；默认跟随系统颜色。`node tools/check-framework-color-picker.mjs` 对照框架源码及原稿资源，仅允许业务/动画接口、中文文案及预设色宽度适配差异；静态检查不能代替两套接口着色和弹层动画的真机验收。

- 颜色面板两个外观模式统一使用框架原有外壳，不再调用 ColorOS 17 面板接口。开启液态玻璃使用框架材质，关闭时使用其纯色 fallback；两者共用中文颜色内容、预设及入场/退场动画。设置页的 ColorOS 17 原组件和底栏保留。

- 颜色预设的加号会保存当前颜色及不透明度，已有的相同颜色不会重复添加；长按色点删除，也支持无障碍“删除预设颜色”操作。预设在四个图标的颜色面板间共用并持久保存，删除默认预设后重进不会恢复；加号紧跟本页最后一个色点，删除时向前补位和跨行，全部删除后位于第一格。新增颜色在原有两行、每页九色的区域内左右翻页，保留 30dp 色点、15dp 行距及原版加号尺寸；默认色保留框架的深浅模式配色，自定义颜色保留完整 ARGB。

- ColorOS 悬浮底栏选择真实 `TYPE_FRAMEWORK_BOTTOM_BAR` 材质分支（`setIsDrawableMaterialEffect(false)`）；关闭额外 Drawable 面板背景路径。原生导航宿主已自带底部间距，应用不再额外叠加 16dp 底距。传入的三个图标跟随原生标题的颜色状态表，适配深浅色和选中状态。

- 设置页新增“界面 → 液态玻璃”开关，默认开启。关闭后通过框架 `ColorOs17SettingsComponents` 调用已安装系统设置包的 COUISwitch、COUISeekBar、COUIBottomFloatingNavigationBar、圆形 COUIFloatingButton 和原生单选日志弹窗；仅保存应用外观偏好，不改变音量面板。不可用时显示原因与切回入口，不仿制 COUI。原控件使用系统 dp/sp，背景采样只录制独立纯色层。会话注册原 COUI 材质状态观察器，跟随系统模糊/轮廓设置并在最后一个会话关闭时释放；右侧重启按钮放在 62dp 槽内居中，使用白色重启图标。接口与限制见 [ColorOS 17 原组件说明](../liquidglass_sketch/docs/coloros17-components.md)。

- TabBar 材质使用框架说明中的“酷安参数”：浅色 `#FAFAFA` / 深色 `#121212`，容器透明度 0.63、回退透明度 0.90、2dp 模糊、指示器折射 7/9.8dp 和 8dp 内阴影。右侧重启按钮共享底栏的背景采样与底色。保持现有 62dp 外框、54dp 指示器、94dp 项宽和全部布局间距；框架未暴露独立的底栏折射高度/强度，沿用原 24/24dp。参考 [框架酷安参数](../liquidglass_sketch/docs/coolapk-parameters.md)。

- 应用图标保留三条音量柱图形，浅色模式使用蓝底白色音量柱，深色模式使用深灰底蓝色音量柱；提供标准自适应图标与单色图层，支持桌面裁切和系统主题图标。桌面是否启用主题着色以及图标缓存刷新由系统桌面控制。

- 基于 ColorOS SystemUI 原生音量面板实现，不使用悬浮窗或自绘音量滑块。
- “禁止应用覆盖系统音量条”默认关闭。开启后，系统按键策略先处理组合键和已消费的事件，其余音量键通过原生音频接口处理，不再交给前台应用的自带音量条。首次使用需在 LSPosed 勾选“系统框架”（`system`）并重启手机；以后开关通过 LSPosed 设置实时同步，不依赖 App 后台存活。应用主动调用接口显示的音量 UI 不在此开关处理范围内。
- 展开后显示多路音量控制，并保留系统原生音量、安全提示、触感和动画逻辑。
- 展开列表宽度跟随底板，清除平板布局的固定宽度和侧边距；音量条动画按底板内的实际父容器坐标定位，避免 OPD2413 等平板出现左侧裁剪、右侧空白及触摸区域错位。收起时恢复列表原生尺寸和边距，保留系统滑块及材质；平板显示仍需实机验证。
- 设置页提供“禁用音量条粗细效果”开关，默认关闭以保留系统行为；开启时阻止侧边音量条及按钮进入原生收窄状态，触摸恢复、按键反馈及展开面板继续使用系统接口。沿用原有设置，升级不会改变已保存的效果。
- “音量条显示在左侧”开关开启为左侧、关闭为右侧，两套接口均使用系统原生侧向布局及动画；新增按钮随原生按钮布局，展开底板贴对应侧边并朝屏幕内部展开。修改后下一次按音量键通过原生配置刷新流程更新位置。
- “竖屏垂直位置”和“横屏垂直位置”两个滑块独立保存，左侧上移、右侧下移，中点还原系统默认位置；移动范围按当前窗口、系统栏和快捷按钮高度计算，两套接口均整体移动原生音量条、按钮及触摸区域。展开继续以移动后的音量条为锚点，下次显示生效；横竖屏显示效果由用户实机验证。
- 面板页“长度”提供“音量条长度”滑块，范围为系统原生长度的 80%–120%，中点默认、右侧文字可还原。两套接口调整原生列表高度，保留名称及阴影留白、宽度、材质和触摸逻辑，展开与收起共用长度；横屏重新计算原生可用长度后再应用比例，不累积缩放。显示时在首帧绘制前根据实际窗口和按钮尺寸复核长度，必要的布局完成后再计算垂直位置，避免第一次使用旧尺寸、第二次才对齐。设置同步到 LSPosed 和持久缓存，下次显示生效，实机效果由用户验证。
- 侧边面板已显示时再次按音量键只刷新新增按钮状态，不重复隐藏、释放材质或重置透明度；退出展开状态时才恢复展开布局，避免关闭自动收窄后按钮闪烁。
- 收起状态增加常用快捷操作，并尽量复用系统原生图标、材质和动画。
- 一加 15 接口的新增按钮使用原生侧边按钮控件，接入按压跟手光效和系统光效开关策略；勿扰开启时保留专用图标颜色。
- 新版接口的新增按钮纳入系统侧边材质宿主列表，参与原生截图刷新、展开还原及释放；重复显示时保留按钮动画状态，缺失背景时重新绑定，关闭自动收窄也继续刷新材质。
- 新增按钮在绘制前同步原生更多按钮的图标颜色、透明度与缩放，首次挂载及自动缩为细条时持续跟随；面板展开、隐藏时移除同步监听。
- 保留 ColorOS 原生模糊、描边和面板材质。
- 面板页“显示”分组提供“流光轮廓”开关，合并原“面板边框高光”，默认开启并沿用原设置。仅控制展开面板底板的光效：Ace 6 控制附加描边，一加 15 控制原生描边、光学和内阴影参数。关闭后保留底色、模糊和内部音量条材质；不读取或写入系统全局轮廓开关。设置持久保存并同步到 LSPosed，下次展开生效。
- 面板以当前显示侧为锚点展开、朝该侧收拢消失，外框边界逐帧跟随另一端的原生音量条位置；音量条和图标保持原尺寸，打断动画时从当前宽度继续。
- 动画边界每帧在绘制前更新一次，材质反射方法缓存复用；横屏按最终布局位置校准，避免顶部受限或原生纵向移动时反复布局。横屏流畅度仍需实机确认。
- 跟随原生音量条时不额外运行计时动画；新版描边在原生平台模糊准备完成后同步，仅写入改变的光照参数，避免每帧重复准备模糊。
- 展开音量条分别保留展开前的背景和填充部分配色，原生材质刷新后仍沿用各自配色；底板以原生音量条背景为基准，默认稍暗。一加 15 接口继续使用控制中心按钮的渐变描边、折射和内阴影，并同步面板圆角。
- Ace 6 的底色层绘制在音量条后面的背景中，前景只保留原生描边；底色调节只作用于底板，展开、消失的边界和透明度继续跟随原生动画。
- 设置页分别用“浅色模式底色”和“深色模式底色”滑块，在默认底色附近以 ±25% 的幅度调节展开底板深浅（两套接口共用），展开时按系统当前模式选择对应值。升级时两个模式继承原来的底色设置，之后独立保存、独立还原；音量条保留原生配色，下次展开时生效。
- 变深同时调整原生混色的透明度，使黑色混色层也能继续加深；保留透明层和原生混合模式。
- 面板圆角滑块范围从直角到当前默认圆角，最右端为默认值；只修改展开底板及描边，音量条保持原有外形，下次展开时生效。设置与 LSPosed 同步保存，旧设置超出默认圆角时归回默认值。
- 静音 / 振动 / 响铃、勿扰、耳机模式三个新增按钮可独立开关；下次显示面板时生效。
- 设置页的“耳机模式切换”列表可勾选关闭、降噪、自适应、通透，右侧勾选标记表示参与点按循环切换。默认选择降噪、自适应、通透，关闭可自行勾选；实际只切换耳机支持且已勾选的模式，全不选或耳机不支持所选模式时隐藏耳机按钮。关闭对应系统的降噪关闭命令，设置与 LSPosed 及持久缓存同步保存，下次显示面板时生效。
- 按钮和面板设置同步保存到 LSPosed，读取不依赖模块 App 后台存活；旧版升级后打开一次设置页完成同步。
- 展开面板收紧音量名称下方留白，可通过“隐藏音量名称”移除文字区域，同时保持原生滑块高度；下次展开时生效。
- 屏蔽音量面板的三段式开关恢复 / 关闭响铃提示，包括收起时的 Toast；保留系统音量控制限制。
- 设置页显示 LSPosed 激活状态，并提供“重启作用域”按钮。
- 设置页顶部参考 Theme：安全区下预留 54dp，大标题使用框架 `Ios27PageHeader(compact = false)` 并随内容滚动，顶部渐进模糊在前 30dp 滚动范围内逐渐出现；按框架说明向 `ProgressiveBlurContent` 传入滚动 `visibility`，保持 `strength = 1f`，使用实际页面 `surfaceColor`。大标题属于滚动内容，固定顶部区域仅为安全区，传入 `appBarHeight = topInset` 和 `scrollDriven = true`，由框架追加 24dp 延伸并调用 ColorOS 17 原生背景渐进模糊接口。接入说明见 [框架渐进模糊说明](../liquidglass_sketch/docs/coloros17-progressive-blur.md)。重启作用域沿用 TabBar 的 splitSearch=true 右侧独立按钮布局（62dp 按钮、16dp 间隔），保留三个 Tab 和无障碍名称。按钮与轨道共用背景采样、2dp 模糊、24/24dp 折射及深浅模式底色叠加，沿用框架描边、阴影和按钮按压反馈。页面录制层和顶部渐进模糊为独立层。
- 设置页参考 Theme 的原版 TabBar，分为带图标的“面板”“快捷”“设置”三页，复用框架玻璃轨道、液滴选择层、拖动与切页动画；面板页将底色、圆角、垂直位置和显示选项分框，左右侧和应用音量条限制也放在显示框内；快捷页包含快捷按钮及耳机模式切换，设置页包含模块版本、LSPosed 状态、桌面图标、日志导出、系统和设备信息及 Hook 日志级别。三页独立保留滚动位置，图标随选中状态及深浅模式变色，底栏为页面录制层之外的浮层，内容预留底部空间。
- 设置页按“模块”“日志”“关于”分组：模块含启用开关、LSPosed 状态和桌面图标开关；日志含 Hook 日志级别与导出日志；关于按左标题、右信息显示模块版本、Android 版本、系统版本和设备型号。启用开关同步到 SystemUI 与系统框架，关闭后使用系统音量面板和音量键策略。
- LSPosed 状态以管理器返回的作用域为准，`com.android.systemui` 与 `system` 齐备时显示“已就绪”，其余显示“未激活”。服务已连接时，点击未激活项通过 libxposed `requestScope` 申请作用域；批准后重新读取状态，取消或失败时保留实际状态。LSPosed 2.2.1 (7912) 仅向已启用模块连接服务，未连接时直接打开管理器的本模块作用域页面，支持独立和寄生管理器。该版申请审批会按安装包过滤作用域，批准后若系统框架仍缺失，也打开作用域页面供用户确认。就绪表示管理器连接与作用域配置齐备，不代表已运行进程重新加载了 Hook。
- 桌面图标通过独立启动别名显示或隐藏，系统保存开关状态，主设置 Activity 和 LSPosed 设置入口仍保留。Hook 日志支持关闭、普通（默认）、调试、详细四档：普通记录常规事件及警告、错误，调试增加面板配置和动画排错信息，详细增加按钮材质、图标动画、触摸区域及布局快照。旧的错误、警告档映射为普通，关闭和调试档保留。级别通过 LSPosed 同步到 SystemUI 和系统框架，并保存在持久缓存，过滤模块的系统日志、管理器日志和导出日志中的新增事件，已有日志仍保留；导出头部同时记录设备、系统和当前级别。
- Hook 日志级别通过一行入口打开框架 Type=Inspector（12740-24122）模态面板，复用 LiquidDialogLayer 的玻璃、透明遮罩及系统底部圆角；高度由内容决定，横屏或大字体超出可用高度时允许列表滚动。面板从底部滑入并淡入，关闭时下滑淡出，动画结束后移除。级别点选即保存，可通过完成按钮、返回键和点击面板外关闭；弹层与底栏位于录制层之外，页面视觉缩放共用。
- 应用设置页按当前可用窗口短边的系统 dp 自动计算视觉缩放：`(短边 / 402).coerceIn(0.85, 1.0)`；标题、列表、控件和 TabBar 共用该比例，横屏及分屏随窗口变化，平板最多保持系统原尺寸。沿用系统字体比例，通过框架 `Ios27AndroidDesignBehavior` 保留系统最小触摸目标策略；安全区按原始像素换算，避免同步缩小系统栏间距。系统音量面板本身不受此页面缩放影响。
- 设置页使用框架分组、列表行和按压遮罩，分隔线居中绘制在两行交界处，遮罩上下边界与分隔线中心重合；滑块拖动仅更新当前分组并在松手时保存，页面后台暂停激活状态轮询。
- 底色滑块上方右侧在默认值时显示“默认”，调整后显示可点击的“还原”，点击即恢复默认值；“导出日志”保留分隔线，操作直接使用框架原有的按压反馈。
- 框架按压反馈直接接收按下、松开事件，短按也会显示遮罩；松开淡出，滑动取消立即清除。
- 标题和底色滑块合为同一控制块，间距收紧 8dp；控制块与“隐藏音量名称”之间保留分隔线。

## 2. ColorOS 17 兼容性说明

- 一加 Ace 6（`PLQ110`）与一加 15（`PLK110`）优先匹配对应方案；其他型号自动检测这两套材质字段及滑块接口，两套均不匹配才保留系统面板。检测结果写入调试日志，接口匹配不代表已完成该机型实机验证。
- Ace 6 使用原生 AutoBlur 材质及描边；一加 15 使用其 `blurHostHelper` 平台模糊材质和新版滑块边界接口。尺寸均从各自 ROM 资源读取。
- Ace 6 有历史实机验证；一加 15 当前依据提供的 SystemUI 17.99.02 APK 完成接口适配，仍需实机验证显示与动画。
- 音量面板作用域为 `com.android.systemui`；“禁止应用覆盖系统音量条”还需要“系统框架”（`system`）。新增系统框架作用域后需重启手机，设置页的重启图标仅重启 SystemUI。1.0.9 误用 `android`，在 LSPosed 2.2.1 / 7912 上不会注入 `system_server`；升级后需重新确认 `system` 已勾选。
- 导出日志头部记录 LSPosed 管理器当前配置的作用域，方便区分面板已激活和系统框架未加载；加载版本仍以各进程日志内的版本标记为准。
- 模块依赖 ColorOS SystemUI 内部类和资源，系统更新后可能需要重新适配。
- 不保证兼容其他 Android ROM、其他 ColorOS 大版本或不同厂商系统。
- 安装或更新模块后需要重启 SystemUI；设置页中的“重启作用域”需要 root 权限。
